# **1. XP (Experience Points)**

**XP adalah mata uang progres yang didapatkan saat user menghafal. XP tidak bisa dibeli dan hanya mencerminkan effort nyata — tidak dapat dikonversi.**

## **Cara Mendapatkan XPA**

- **1 step hafalan jika benar = 4 XP**
- **XP murni mencerminkan progres — tidak bisa dibeli atau dikonversi**
- **1 misi harian = 35 XP**

## **Fungsi XP**

- **Leveling dan ranking leaderboards**
