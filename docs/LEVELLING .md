# PROLOGUE

Menghafal Quran perlu sistem. User ditentukan levelnya berdasarkan onboarding yang berfungsi sebagai levelling map

# 3 STEPS LEVELLING

## Begginer Level (JUZ AMMA)

Level ini adalah permulaan untuk para pengguna yang baru mulai menghafal Quran. Terutama untuk mualaf, awam yang pertama kali menghafal, dll. Target besarnya adalah juz 30 (Juz Amma), yang kemudian dibagi menjadi mini target. 

### Key Ingridient:

- As fun as possible
- As easy as possible
- Experimental audio
- Stepnya banyak, kecil-kecil, membiasakan user dengan ayat demi ayat
- Pengenalan menghafal Quran

<aside>
💡

### MINI TARGET JUZ AMMA

An-Naziat — An-Naba’ = badge per juz

**#Tangga ketiga**

Al-Layl — At-Takwir = check point

**#Tangga kedua**

An-Naas — Ad-Dhuha = check point

**#Tangga pertama**

</aside>

## Mid Level (TABARAK, 28, Al-Waqiah, Ar Rahman)

Level ini adalah level lanjutan setelah level pertama. Ditujukan bagi user yang sudah pernah menghafal Juz Amma dan ingin melanjutkan hafalannya, user yang telah menyelesaikan hafalannya di begginer level, dll. Targetnya dibuat 2-3× lebih besar dari target di Begginer Level, namun tetap dibagi ke dalam mini target 

### Key Ingridient:

- As fun as possible
- As easy as possible
- Experimental audio
- Stepnya banyak, kecil-kecil, membiasakan user dengan ayat demi ayat

<aside>
💡

### MINI TARGET (Per Juz = 1 Tangga) (Per Juz - Per Surah)

Juz 29 

1. Al-Mulk, Al-Qalam, Al-Haqqah 
2. Al-Ma’arij, Nuh, Jin, Al-Muzzammil 
3. Al-Mudatsir, Al-Qiyamah, Al-Insan, Al-Mursalat

Juz 28 

1. Al-Mujadalah, Al-Hasyr, Al-Mumtahanah
2. As-Saff, Al-Jumuah, Al-Munafiqun
3. At-Taghabun, At-Talaq, At-Tahrim 

Al-Waqiah

Surat ini opsional, boleh dibuka di mid boleh juga di save untuk nanti di pro level

Ar-Rahman

Surat ini opsional, boleh dibuka di mid boleh juga di save untuk nanti di pro level

</aside>

## PRO LEVEL (JUZ 1-27)

Level ini ditujukan bagi user yang telah menyelesaikan Mid Level atau user yang sudah memiliki hafalan sebelumnya dan ingin melanjutkan secara sistematis. Target besarnya adalah Juz 1-27. Dengan target yang begitu besar, PRO LEVEL tetap memiliki mini target.  

User yang memilih PRO LEVEL memiliki intensi yang lebih kuat. Dengan asumsi telah lebih dulu berpengalaman dan memiliki hafalan, maka learning path yang diberikan lebih serius — tapi tetap fun (inshaAllah)

### Key Ingridient:

- Dicipline over fun
- Audio - visual experience
- More focus, new learning path
- Badge per surah dan per juz
